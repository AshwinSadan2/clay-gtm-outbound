## Key decisions

| # | Decision | Why |
|---|---|---|
| 1 | **Rule-based variables (`{ROLE}`, `{PS_LINE}`) are always deterministic Python, never an LLM** | Predictable, free, auditable. LLM only where judgment is needed (saved as a memory) |
| 2 | `{ROLE}` adds `cmo`, `chief marketing` to the marketing rule | Otherwise "CMO + AI GTM" became "revenue leaders" through the word GTM |
| 3 | Rules are flags, not code (`--rule label=keywords`) | Flags-not-config: a new campaign never edits the script |
| 4 | Model `gpt-6-luna`, effort `none` | Cheapest GPT-6; `none` is the only effort with log-probability confidence and temperature |
| 5 | Two-pass opener: insight → compose; the writer never sees the raw bio | The owner's design: an extraction call, then a writing call |
| 6 | **No prompt text in code**: prompts and their settings live in versioned `.md` files; never edit a version that has run | Every result traces to a prompt version (`_prompt`) and settings (`_settings`) |
| 7 | Contact About under **50 words** → Variant B (company About) | Owner: thin bios write worse lines. 29 of 96 go to B |
| 8 | v2: prefer current work, ONE thing not a list, B max 15 words · v3: never start "you focus on" | Owner's review of rows 1–20 |
| 9 | Script runs ONE prompt per run; a pipeline is chained by columns | Owner: tomorrow's pipeline may have 4–5 stages; the script must not care which stage it is |
| 10 | Concurrency default 25 | Owner's choice; Luna allows 5,000 requests/min |
| 11 | Confidence = exp(mean log-probability) of the answer's own tokens, JSON scaffolding excluded | The only confidence signal OpenAI exposes |
| 12 | Checks flag, never fix; `--fail-on greeting` is a hard fail | A doubled "Hey Name," visibly breaks the email |
| 13 | Prompt iteration on a separate sample sheet that grows 10 → 20 → 30; full run only on the live sheet | Owner's choice: like-for-like plus fresh rows each round |
| 14 | Scale step asks "run now at the projected cost, or Batch (≈50% cheaper, ≤24h)"; Batch mode built later | Owner: offer it later |
| 15 | Skill name `variable-llm-pipeline`; prompts in `docs/prompts/<variable>/` | |

## Issues and notes

- **Folder casing:** the owner's prompts arrived in `docs/Prompts/` (capital P). Moved to
  `docs/prompts/opener/`.
- **Logprobs vs reasoning:** OpenAI returns 400 "logprobs are not supported with reasoning models" for any
  effort above `none`. The same applies to temperature.
- **Curly apostrophes** (`doesn’t`) defeated the first review-phrase match. Fixed by normalising before
  matching.
- **Insight v2 never admits "no link":** it always produces a hedged pain, so the `review` flag fired only
  once in 96. A future insight version should allow "No clear link".
- **`--max-cost` can overshoot by up to one batch:** rows already running finish.
- **Estefania (row 39)** got an opener starting "Hey Estefania," in the v3 run. With `--fail-on greeting` this
  can no longer reach the sheet.
- **Answers about Art's opener and `_v2` columns** came in that match nothing in this project (Art's opener
  is clean, and no `_v2` columns exist). Not acted on; the owner was asked.
