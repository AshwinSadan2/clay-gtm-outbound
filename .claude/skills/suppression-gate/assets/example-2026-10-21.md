Answers: level **domain** · categories **all** · window **90 days** · target **Supabase gtm.companies**.

```bash
S=.claude/skills/suppression-gate/scripts; PY=.venv/bin/python
F='--level domain --categories all --days 90'
bash $S/probe_connections.sh                                # Attio + Supabase OK
$PY $S/attio_profile.py  $F                                 # stage 1: 30 domains
```
